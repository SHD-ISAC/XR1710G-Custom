## Integration

- Keep the upstream forward-path bailout in place of patch 699. If a
  neighbour or path is unresolved, fall back to classic forwarding
  instead of installing an offloaded flow with incomplete metadata.
  Rebase the local bridge, VLAN passthrough and WDMA cases onto the
  error-returning parser. Require both bridge directions to resolve,
  release both route references on error, and preserve LAG and routed
  XFRM/SOE handling. Keep the new roaming check's reset of VLAN counts
  at each bridge.
- Update mt76 by 83 source commits, including the matching radio firmware.
  Use the upstream scan dwell capability once. Preserve the upstream
  shared MLD replay counter while rebasing the local WCID lookup patch.
  Keep the power-path tables and one SKU enable; route backoff setup
  errors through the new radio shutdown path. Use the 160 MHz
  beamforming fallback for EHT320 with the upstream zero-NSS clamp.
- Keep the per-radio transmit-power configuration and the NPU/NAPI
  teardown fixes. Use the upstream mac80211/Wi-Fi changes, including
  transmit encapsulation authorization fixes, and version the local
  mac80211 and wifi-scripts packages separately.
- Retain `dnsmasq-full` and IPv6, with DNSSEC, DHCPv6, nftset and
  conntrack. dnsmasq 2.93-r12 adds ubus reconnection fixes, atomic
  resolver updates and a reduced set of jail capabilities. The pinned
  procd includes the corresponding `SECBIT_KEEP_CAPS` fix.
