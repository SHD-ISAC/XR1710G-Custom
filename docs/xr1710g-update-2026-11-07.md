The XR1710G DTS, flash layout, compatibility version 2.0, board scripts,
port mapping and firmware seed are unchanged. Retain YYH's direct MAC
netdev naming; the removed Airoha label preinit hook stays removed. This
update does not install a bootloader. The upstream target enables KASLR
and adds the EN7581 thermal IRQ ordering fix.

## Integration

- Keep the upstream forward-path bailout in place of patch 699. If a
  neighbour or path is unresolved, fall back to classic forwarding
  instead of installing an offloaded flow with incomplete metadata.
  Rebase the local bridge, VLAN passthrough and WDMA cases onto the
  error-returning parser. Require both bridge directions to resolve,
  release both route references on error, and preserve LAG and routed
  XFRM/SOE handling. Keep the new roaming check's reset of VLAN counts
  at each bridge.
- Update mt76 by 83 source commits, including the matching radio firmware.
  Use the upstream scan dwell capability once. Preserve the upstream
  shared MLD replay counter while rebasing the local WCID lookup patch.
  Keep the power-path tables and one SKU enable; route backoff setup
  errors through the new radio shutdown path. Use the 160 MHz
  beamforming fallback for EHT320 with the upstream zero-NSS clamp.
- Keep the per-radio transmit-power configuration and the NPU/NAPI
  teardown fixes. Use the upstream mac80211/Wi-Fi changes, including
  transmit encapsulation authorization fixes, and version the local
  mac80211 and wifi-scripts packages separately.
- Retain `dnsmasq-full` and IPv6, with DNSSEC, DHCPv6, nftset and
  conntrack. dnsmasq 2.93-r12 adds ubus reconnection fixes, atomic
  resolver updates and a reduced set of jail capabilities. The pinned
  procd includes the corresponding `SECBIT_KEEP_CAPS` fix.

## Checks before the full build

- 270 generic/Airoha patches apply without fuzz on 103 focused runtime
  files from pristine Linux 6.18.60. This is a focused patch preparation
  check; the full build prepares and compiles the complete target.
- All 288 mac80211 patches and all 31 mt76 patches apply with zero fuzz.
  Ten mac80211 management-frame tests and 18 mt76 tests pass. The mt76
  suite exercises the updated link teardown helper and verifies that a
  station remain-on-channel operation is aborted before freeing the link.
- Seven existing Wi-Fi forward-path cases and nine new Netfilter cases
  pass. The latter compile the prepared parser and bridge route function:
  tagged and nested bridges, incomplete paths, unknown paths, an
  unregistered egress, excessive VLANs, and preservation of routed XFRM.
  A negative control ignoring reverse-path failure fails the corresponding
  regression. The 44 host tests run in the firmware workflow.
- The dnsmasq init script passes shell syntax validation. The full build
  also runs the existing DNS/DHCP configuration checks on the built ARM
  dnsmasq under QEMU.
